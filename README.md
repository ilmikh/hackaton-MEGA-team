# Велореестр — фронтенд Azik

HTML, CSS и JavaScript без фреймворка. Бэк команды — FastAPI. Изменения этой части выполняются в ветке `azik`.

Готовы: профиль (имя и контакт), свои велосипеды, отдельная страница велосипеда, регистрация с выбором места, изменение описания, просмотр и скачивание QR в PNG, сканирование камерой/по фото/по ссылке. QR-результат закрывается крестиком, можно сканировать следующий код. Админу доступны полный результат, комната владельца из ответа бэка и профиль владельца.

Карта и заявки закреплены за вторым фронтенд-разработчиком. Для них добавлены кнопки, переходы и события подключения, сами разделы в этой части не реализованы. Без подключения реального API рабочий режим не подменяет данные демоданными.

## Посмотреть

Запустить из корня `python -m http.server 8000`, затем открыть [демо](http://localhost:8000/frontend/demo/index.html). Желтая плашка обозначает деморежим, его данные хранятся только в браузере.

- [Инструкция для FastAPI и тиммейта: API, поля, ошибки и события](docs/FRONTEND_API.md).
- [Галерея ровно восьми актуальных макетов](docs/design/index.html).
- [Описание макетов](docs/design/README.md).
- Рабочая точка входа: `frontend/index.html`, без зависимости от Django.

## Проверки

`tests/frontend.cjs` — целевые браузерные проверки через Playwright; порядок запуска и границы проверки описаны в инструкции. Проверены демо и API-адаптер на тестовых HTTP-ответах. Реальный FastAPI, вход, ЛКП и физическая камера требуют подключения и проверки с бэком.

`.gitignore`, временные архивы npm, результаты тестов и старые макеты в поставку не включены.
