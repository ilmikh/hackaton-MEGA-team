# Велореестр — HTML/CSS, часть Azik

Поставка содержит **только HTML и CSS** интерфейса. JavaScript, клиентская генерация и распознавание QR, API-адаптер и демологика удалены.

## Запуск

Из корня репозитория: `python -m http.server 8000`.
Открыть [основной интерфейс](http://127.0.0.1:8000/frontend/index.html).
Сервер нужен только для удобного просмотра файлов; собственный бэк здесь отсутствует. Можно также открыть frontend/index.html как обычный HTML-файл.

## Страницы

- frontend/index.html — профиль: имя и контакт, без дублей велосипедов/заявок.
- frontend/bikes.html — собственные велосипеды; клик на карточку ведёт на отдельную страницу.
- frontend/bike.html и bike-forward.html — отдельные карточки.
- frontend/register.html — фото, модель, цвет текстом, необязательные приметы, место для подключения карты.
- frontend/edit-bike.html — форма описания.
- frontend/scan.html — выбор фото/снимка QR и явно подписанный пример ответа.
- frontend/admin-profile.html, admin-bike.html, admin-edit-bike.html, admin-owner.html, admin-scan.html — административные варианты.
- frontend/map.html, requests.html и административные аналоги — только точки подключения части тиммейта.
- frontend/static/veloregistry/app.css — общие стили и адаптивность.

Ссылки, выбор файлов и CSS-окна работают средствами браузера. Сохранение отключено, запросов и хранения данных нет. Имена и велосипеды в макете вымышленные. «Пример результата» не распознаёт выбранный QR.
