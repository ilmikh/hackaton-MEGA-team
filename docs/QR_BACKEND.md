# QR — ответственность бэка

HTML/CSS-макет не генерирует и не распознаёт QR. JavaScript и QR-библиотеки удалены.

## Разметка
scan.html и admin-scan.html содержат:
- выбор снимка через input type=file с capture=environment;
- выбор JPG/PNG/WebP;
- отдельно подписанный «Пример результата», открывающий CSS-окно через :target;
- закрытие и «Сканировать ещё» как обычные ссылки.

Выбранный файл не отправляется. На страницах велосипеда «Мой QR» открывает заглушку для готовой картинки сервера. Скачивание disabled до подключения.

## Что подключает бэк
- form action + method=post + enctype=multipart/form-data для фото; имя поля согласовать (qr_photo или camera_photo).
- Проверку реального формата/размера файла, распознавание QR, разбор разрешённой собственной ссылки, поиск объекта.
- Генерацию постоянной QR-ссылки/токена и PNG.
- Настоящий ответ вместо статичного примера: жильцу номер велосипеда, имя и способ связи; админу полная карточка, место, данные комнаты из ЛКП.
- Готовую картинку и ссылку скачивания после проверки прав.
- Ошибки «QR не найден», «Неизвестный код», «Нет доступа» и повторную загрузку.
- Обработку QR парковки с переходом в карту/места согласно роли.

Не загружать произвольный URL из QR на сервере: проверить origin/формат и найти свой объект. Отсутствие владельца показывать явно. Фото QR само по себе не даёт права редактировать велосипед.
Для варианта без JS бэк может отвечать отдельной HTML-страницей или серверно показывать результат в шаблоне. Динамическую работу камеры и автоматическое окно после запроса HTML/CSS не выполняют.
