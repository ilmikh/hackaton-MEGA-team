# QR — бэкенд

В статичном index.html экраны #page-scan и #page-admin-scan содержат выбор снимка/файла и отдельно подписанный пример ответа. Клиентского JS нет; файл не отправляется и не распознаётся.
«Мой QR» открывает заглушку для готового изображения сервера. Кнопка скачивания disabled.

Бэк подключает:
- форму загрузки, проверку реального типа/размера файла;
- распознавание, проверку собственной ссылки/токена и поиск объекта;
- генерацию постоянной ссылки и PNG, проверку прав при выдаче;
- ограниченный ответ жильцу (номер, имя, контакт) и полный админу (включая комнату ЛКП);
- ответ по парковке с переходом в карту/места;
- ошибки и возможность повторной загрузки.

Поля выбора: camera_photo и qr_photo; перед подключением согласовать одно поле/обработчик.
capture=environment — подсказка мобильному браузеру, на компьютере может открыться обычный выбор файла.
Не загружать произвольные URL из QR: проверить origin/формат, найти собственный объект.
CSS-пример ответа не является результатом распознавания. Node.js в этой поставке лишь раздаёт файлы и не выполняет QR-логику.
