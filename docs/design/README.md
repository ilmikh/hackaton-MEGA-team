# Актуальные макеты

Ровно восемь PNG, старые версии не включены. Открыть index.html для просмотра.

1. [Профиль — только имя и контакт](01-profile.png)
2. [Свои велосипеды — переход кликом](02-my-bikes.png)
3. [Регистрация с выбором места](03-registration.png)
4. [QR жильца](04-user-qr.png)
5. [Карта парковок — часть тиммейта](05-map.png)
6. [Заявки — часть тиммейта](06-requests.png)
7. [Админ — карта и списки](07-admin-map.png)
8. [Админ — результат QR](08-admin-qr.png)

Созданы встроенным image_gen; это концепты, не скриншоты сайта. Данные ЛКП, схема и числа демонстрационные. У жильца нет полного реестра. Комната — только админу. Регистрация включает выбранное свободное место. Страница своего велосипеда отдельная, без кнопки «Открыть» в списке.

Карта и заявки реализуются тиммейтом. Азик реализует профиль, велосипеды/регистрацию и QR. На сгенерированном изображении заявок фраза об уведомлении не добавляет push/email в MVP: состояние показывается в списке.
